# Exergy privacy policy (source)

Published: [thebonhomme.com/Exergy/privacy/](https://thebonhomme.com/Exergy/privacy/).

Exergy meters remaining quota on the user’s Apple devices. Le Bonhomme Pharma does not collect, receive, or keep account tokens, prompts, or usage history on our servers. There is no Exergy account.

Sync uses Apple iCloud (CloudKit private database) for **non-secret** meter snapshots the user opts into. OAuth tokens and API keys stay in the Keychain. Optional iCloud Keychain sync of those secrets is off by default and, when enabled, is Apple’s end-to-end Keychain — not a CloudKit record we can read.

When you connect GitHub, Anthropic, Google, OpenAI, or xAI, those companies process the request under their own terms. We never see the token.
