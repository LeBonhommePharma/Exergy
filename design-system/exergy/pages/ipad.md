# iPadOS — split canvas

Overrides MASTER for `Apps/iPad`.

- **Nav:** `NavigationSplitView` sidebar (Usage / Add / Settings), not a phone tab bar scaled up.
- **Measure:** usage column max readable width 720pt; larger gutters.
- **Hits:** sidebar rows min 44pt.
- **Detail:** one surface at a time (no duplicated home in sidebar *and* detail).
- **Do not:** edge-to-edge paragraphs; collapsing the sidebar into 3 stacked phones.
